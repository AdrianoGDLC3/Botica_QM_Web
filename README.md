# Botica Q&M

Sistema web de gestión para una botica.

## Arquitectura

- `botica-frontend/`: interfaz web desarrollada con React y Vite.
- `botica-api/`: API backend desarrollada con Java y Spring Boot.
- `docs/`: manuales y documentación técnica.

## Base de datos

El proyecto utiliza Supabase/PostgreSQL. La configuración de producción debe realizarse mediante variables de entorno; no publiques contraseñas ni claves secretas.

## Desarrollo local

Consulta el README de cada componente y la documentación de `docs/` para conocer los requisitos y los pasos de ejecución.
